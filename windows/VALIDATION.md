# Windows 预览版验证记录

2026-10-19，Surface Pro 6，Windows 10 Pro 22H2 x64 / build 19045，Intel i5-8250U、8 GB RAM、SK hynix BC501 NVMe 128 GB。

- MSVC 19.44、Windows SDK 10.0.26100、Release x64 静态运行库编译成功。
- 8 项计数与分类检查、8 项系统 SQLite 持久化检查通过。
- 两次隔离的 22 秒实机采样，使用局域网 HTTP 传输 16 MiB 文件，并在 Windows 端执行 16 MiB WriteThrough 文件写入。
- 两次下载均归属于 PowerShell，报告下载量为 16,777,421 字节（包含 HTTP 响应头）；固定写入被归属于 PowerShell。网卡总量单独保留，没有用应用排行加总替代。
- 两次采样的 TDH 解析失败和 ETW 丢失事件均为 0；存在无法归属到活动线程的磁盘事件，已单列，不强行归到 System。
- SQLite 记录正常保存，重新打开和日期范围查询已由持久化检查覆盖；CSV 导出检查通过。
- NVMe 原始日志可读取温度、主机读写、耐久度已用、通电时间与介质错误，不使用 WMI 缺省的 0 填补缺失字段。
- 在登录用户的交互桌面运行，已获取网络、磁盘读写、磁盘状态三页真实窗口截图，并检查布局。
- 短时采样：仅诊断采集进程工作集约 14 MB、私有内存约 3.4 MB；交互桌面进程工作集约 42 MB、私有内存约 16 MB，一次 10 秒 CPU 样本约 0.2%（按逻辑处理器总数归一化）。这些是特定机器和负载下的观察值，不是资源上限或长期保证。
