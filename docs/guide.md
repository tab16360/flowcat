# 流量喵 1.3

适用于 Apple 芯片 Mac，macOS 13 或更新版本。两台机器可以分别安装，各自统计本机流量。

## 安装与使用

1. 将 `流量喵.app` 拖入 Finder 的“应用程序”文件夹。
2. 双击启动。它只显示在屏幕顶部菜单栏，不显示 Dock 图标。
3. 左键点击菜单栏的猫咪图标（开启网速时也显示下载速度），打开面板，切换“今日 / 昨日 / 本月”。右键或 Control 点击可使用打开面板、暂停／继续、登录启动、导出和退出快捷菜单。
4. 打开右上角“更多”菜单，勾选“登录时自动启动”，让它从登录后持续记录。若 macOS 要求批准登录项，请在系统设置中确认。
5. 点击“导出 CSV”选择保存位置，可用 Numbers / Excel 查看。

## 菜单栏显示

默认显示猫咪主图标和下载速度，已有手动开关选择继续保留。右键菜单栏图标，或打开面板右上角“更多”，切换“菜单栏显示网速”。开启后显示整机下载速度；关闭后隐藏速度和箭头，主图标继续保留。选择立即生效并在重启后保留，不影响流量采集。

隐藏网速时，悬停图标仍可查看今日网卡总量；暂停时提示“已暂停”，可通过右键菜单继续记录。

## 更新

右键菜单栏图标或打开“更多”，选择“检查更新”。1.4.0 起，有新版时选择“安装并重启”：在应用内下载、校验并准备替换，旧版保存记录并退出后整体更换应用，再自动启动新版。历史文件和已保存的设置保留，下载阶段可取消。

- 校验官方地址、下载大小、SHA-256、ZIP 路径、应用身份、版本及代码签名；签名团队已建立时不允许换团队或降级为无团队签名。
- 更新进程等待新版启动确认；替换或启动失败会恢复旧版。成功后在 `~/Library/Caches/local.gww.trafficledger/Updates/previous.app` 保留一份上一版应用。
- 当前安装目录需要可写。从磁盘映像、App Translocation 或不可写目录运行时，请先移到可写的“应用程序”目录再更新；不自动提权。
- 1.3.x 的更新器只支持浏览器下载，需先安装一次 1.4.0，之后即可应用内更新。
- 更新只由你手动触发，访问 GitHub 获取版本和安装包，不上传流量记录。当前仍为临时签名，安装校验不等同于 Apple 公证。

## 互联网与局域网

默认查看“全部流量”，便于看到应用通过代理或 VPN 产生的记录。“全部流量”仍为物理网卡总量，包含 Time Machine、SMB 文件传输等局域网活动。“互联网”“局域网”展示升级后采集的连接估算和各自的进程排行，支持与时间、Wi-Fi 筛选组合使用，CSV 包含分项记录。

- 只分类绑定到 `en*` 物理接口的 TCP/UDP 连接，排除回环、代理本地连接和 VPN 虚拟接口。
- 对端为私有、链路本地地址，或属于当前物理网卡 IPv4/IPv6 子网时计入局域网；公网对端计入互联网。Fake-IP、CGNAT/隧道地址及未知对端不强行归类。
- 分项显示独立采样覆盖时间。旧历史没有连接信息，不能补分；没有分项记录不表示实际没有传输。
- 新连接先建立计数基线；短时或已关闭连接、未知 UDP 对端、协议开销可能遗漏。分项与网卡总量不是同一统计口径，不能相加或相减得到精确账单。
- VPN、代理只能识别物理接口上的外层连接，不能据此外推隧道内实际目标。内核承担的 SMB 等传输仍可能显示为 `kernel_task`。
- 连接地址仅用于内存中的采样分类，历史只保存各范围的字节和进程汇总。

流量范围筛选右侧显示“当前连接 · Wi-Fi 名称”。点击即可筛选当前网络，不改变时间和流量范围；使用网络选择菜单后，点击面板外可收起面板。

## 按 Wi-Fi 名称统计

- 网络名称直接使用当前连接的真实 Wi-Fi SSID，不预设热点分类、不自动改名、不提供手动标记。
- 无法读取 Wi-Fi 名称且系统尚未作出授权决定时，应用主动请求系统定位权限。macOS 使用该权限控制 Wi-Fi 名称读取；你可以拒绝。应用不会请求或记录位置坐标。
- 未授权、读取失败或使用有线网络时，界面只显示“全部网络”，继续记录整机和进程流量。不会出现未分类、未识别网络等占位分类。
- 能读取 Wi-Fi 时，网络筛选器提供全部网络和已经记录的真实 Wi-Fi 名称，可组合今日、昨日、本月筛选。
- 切换网络时跳过跨界采样间隔，避免混记；代价是最多约一次采样的漏计。
- 多个物理网卡同一采样都有数据时，只计入全部网络，避免将所有数据误归到当前 Wi-Fi。
- 旧版本历史总量保留在“全部网络”；有原始 SSID 的记录按原始名称展示，不再使用手动标签。
- 弹窗按当前屏幕可用宽高自适应，极矮屏幕可滚动整个内容。

升级时先在旧版菜单中点击“退出”，替换应用，再启动。历史文件路径未变，不要删除它。

## 1.3 界面调整

- 顶部集中展示时间和网络筛选；累计流量独立成卡片，实时速度明确标为整机数据。
- 进程列表支持名称搜索，按总流量、下载量或上传量排序；长名称可悬停查看。
- 登录启动和退出收进右上角“更多”菜单；统计说明可展开，减少常驻信息。
- 使用不透明背景及明暗两套配色；小屏支持整页滚动，进程列表独立滚动。
- 真实 Wi-Fi 名称、可拒绝的权限请求、无法识别时只显示全部网络的行为保持不变。

## 统计含义

- **整机网卡流量**：来自 `en*` 网络接口的收发增量，通常包括 Wi-Fi、以太网、USB 网络。排除 `lo0` 和 VPN 虚拟接口，避免把同一批隧道流量直接重复相加。
- **应用／代理与 VPN**：默认显示应用排行，已识别的代理内核和 VPN 在单独列表展示。切换控件与排行标题、排序位于同一行。分类只改变展示，既有历史、网络筛选、原始计数和 CSV 均保留。未识别的转发程序仍可能出现在应用列表；两份列表不能相加。
- **进程数据**：来自 macOS `nettop` 的进程收发增量；能获取路径时将同一个 App 的辅助进程合并到该 App。
- 进程数据可能包含回环、代理和 Tailscale/VPN 转发，因此**不能把排行的各行加起来作为热点计费总量**。
- 网卡总量还包含局域网、网络协议开销，不能替代手机/运营商账单；若同时连接多个物理网卡，会汇总多个网卡的流量。
- 10 秒采样一次，每分钟保存一次，正常退出时再次保存。异常退出最多可能丢失最后一分钟尚未保存的记录。
- **只记录工具正在运行且未暂停的时间**，无法补算安装之前、退出期间或睡眠期间的历史。
- 首次启动后的前 10 秒用于建立基线。短时进程、进程退出及接口/计数器重置可能漏计，属于采样式统计而非计费审计。
- 午夜分界精度约一个采样间隔；日期和月份按机器当前时区确定。
- “已监控小时数”表示实际采集覆盖时间，便于判断一天的记录是否完整。

所有历史保存在本机：

```
~/Library/Application Support/流量账本/ledger.json
```

无需账号，不上传数据，不抓取通信内容，不修改代理、防火墙或连接方式。

代理转发记录不能直接拆回原始应用：当前历史只保存各进程累计量，没有保存连接与应用的对应关系。代理的上传也可能包含向本地应用回传的数据。应用列表并非扣除代理后的精确外网用量。

## 如何找耗流量的程序

先让工具运行 10–20 分钟，观察进程排行。针对热点开发场景，可分别记录 UU 连接和断开各 5 分钟，比较整机总量的增量。代理与 Tailscale 排名高时，它们可能只是代其他程序转发数据。

## 验证情况

- 原生 Apple 芯片应用构建成功，应用签名及 plist 可验证。
- 1.3 明暗配色的正文、辅助文字和强调色在两种背景上的计算对比度最低分别为 5.75:1、7.58:1。此项为颜色计算，不能代替实际界面验收。
- 128 项核心、磁盘与更新检查通过：进程计数解析、64 位大计数、接口去重、计数器重置、今日/昨日/跨月、本月汇总、独立网卡总量、历史持久化、网络分类隔离、旧历史兼容、小屏弹窗尺寸等。
- 本机采样已运行并用于资源观察；图形自动化未获该应用访问权限，因此**完整菜单栏交互、定位授权弹窗和面板开关循环尚未验收**。请从 Finder 正常启动；若弹窗内显示“采集不可用”，请把提示反馈回来。

项目的 `Sources/` 目录内包含 Swift 源码与原生 IOKit C 桥接。安装 Xcode Command Line Tools 后，可以运行：

## 磁盘读写与健康

在顶部切换“磁盘”，再选择“读写统计”或“磁盘状态”。读写统计支持今日、近 7 天、近 30 天、累计与按日查看。默认按写入量排行，可搜索进程、调整排序、点行查看路径与归属说明，导出当前时间范围的每日 CSV。历史单独保存在 `disk-ledger.json`，不修改网络的 `ledger.json`。

进程计数覆盖所有磁盘，应用辅助进程合并。只累计实际观察到的增量，首次启动只建基线，睡眠/暂停/漏采不补零。计数无法反映安装前历史，部分系统进程和短暂进程无法完整覆盖。

磁盘状态按物理磁盘查看。硬件提供哪些指标就显示哪些；未提供不等于故障，也不显示成 0。SMART 正常是磁盘自身报告状态，不是故障保证；耐久度已用不等于剩余寿命。累计主机写入与软件记录期间的进程写入口径不同，不应相互相减或推算闪存磨损。外置盘取决于硬盘盒透传能力；不需要安装第三方驱动或关闭系统保护。

右键或“更多”可独立开启“菜单栏显示磁盘读写”，默认关闭，原来的网速开关继续保留。健康页按需读取，之后约每 10 分钟刷新，也可手动刷新。全局暂停会暂停进程读写统计，仍可手动读取健康状态。
